# PIP Launcher

[Скачать PIP-Launcher.exe для Windows x64](https://github.com/sergeynak/pip-launcher-releases/releases/latest/download/PIP-Launcher.exe)

Переносимая версия без установщика. Сохраните EXE в папку, доступную для записи, и запустите. Требуется Microsoft Edge WebView2 Runtime.

При запуске показывается заставка, проверяются обновления, затем открывается вход. Новая версия скачивается и проверяется по цифровой подписи; после замены EXE лаунчер перезапускается. При недоступности сети можно повторить проверку или продолжить без обновления.

Версия 0.1.2 — первая с автообновлением. Более раннюю версию нужно один раз заменить вручную.

Проект пока является прототипом: вход демонстрационный, игровые режимы и запуск Minecraft представлены заглушками. Используйте вымышленные данные для входа.

В репозитории публикуются готовые сборки и файлы проверки обновлений. Для запуска скачивайте только `PIP-Launcher.exe`; `latest.json` и `latest.json.minisig` использует сам лаунчер.
