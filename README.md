# PIP Launcher

Релизы пока не опубликованы. Раздача обновлений планируется с собственного HTTPS-сервера; адрес ещё не выбран. Этот репозиторий сохранён как резервный вариант для готовых сборок.

Переносимая версия без установщика. Сохраните EXE в папку, доступную для записи, и запустите. Требуется Microsoft Edge WebView2 Runtime.

При запуске показывается заставка, затем открывается вход. После подключения сервера новая версия будет скачиваться и проверяться по цифровой подписи; после замены EXE лаунчер перезапустится. При недоступности сети можно будет повторить проверку или продолжить без обновления.

Версия 0.1.2 содержит механизм автообновления, но сетевые проверки отключены до выбора сервера. Для подключения сервера потребуется новая сборка и однократная замена EXE вручную.

Проект пока является прототипом: вход демонстрационный, игровые режимы и запуск Minecraft представлены заглушками. Используйте вымышленные данные для входа.

В репозитории публикуются готовые сборки и файлы проверки обновлений. Для запуска скачивайте только `PIP-Launcher.exe`; `latest.json` и `latest.json.minisig` использует сам лаунчер.
